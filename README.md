
# Smart Greenhouse System 🌱

An automated greenhouse monitoring and control system developed for the **Design with Microprocessors (DMP)** course. This system monitors environmental conditions in real time and automatically regulates irrigation, temperature and lighting to maintain optimal plant growth. 

*[I might add on this as I keep working on the project]*

## 🚀 Key Features
* **Environmental Monitoring:** Real-time temperature, air humidity and temperature tracking.
* **Climate Control:** Triggers an electric fan when temperatures go above a set value.
* **Light Regulation:** Measures ambient light and switches grow lights on in low-light conditions.
* **Live Status Display:** Outputs real-time sensor readings and actuator states to an LCD screen.

## 🛠️ Hardware Components

* **Microcontroller:** Arduino Mega
* **Sensors**:
  * Light Sensor
  * Humidity Sensor
  * Temperature Sensor 
* **Actuators:**
  * DC Cooling Fan
  * LEDs (Grow Light)
* **Display:** 16x2 LCD Display
